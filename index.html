Déployer React.js sur GitHub Pages

Guide complet pour héberger votre application React gratuitement

Objectif

Mettre en ligne une application React.js sur GitHub Pages, en créant un build optimisé et en l'hébergeant gratuitement.

GitHub Pages est un service d'hébergement gratuit de sites statiques intégré à GitHub. Parfait pour les applications React compilées !

Prérequis

  • Avoir Node.js installé ➜ https://nodejs.org
  • Avoir un compte GitHub ➜ https://github.com
  • Avoir installé Git sur votre PC ➜ https://git-scm.com
  • Avoir un projet React prêt (nous utiliserons create-react-app dans l'exemple)

Assurez-vous que Node.js est bien installé en exécutant node -v et npm -v dans votre terminal.

Étapes détaillées

1

Créer un projet React (si nécessaire)

Si vous n'avez pas encore de projet React, créez-en un avec create-react-app :

npx create-react-app mon-app cd mon-app

Cette commande installe tous les packages nécessaires et configure votre environnement de développement.

2

Installer gh-pages

Ajoutez le package gh-pages qui permet de déployer facilement sur GitHub Pages :

npm install gh-pages --save-dev

Cette bibliothèque va automatiser le processus de déploiement en gérant la création de la branche gh-pages et le déploiement des fichiers compilés.

3

Modifier le fichier package.json

Ouvrez le fichier package.json et apportez les modifications suivantes :

{ "name": "mon-app", "version": "0.1.0", "private": true, "homepage": "https://VOTRE-NOM-UTILISATEUR.github.io/NOM-DU-DEPOT", "dependencies": { // Vos dépendances existantes }, "scripts": { "start": "react-scripts start", "build": "react-scripts build", "test": "react-scripts test", "eject": "react-scripts eject", // Ajoutez ces deux lignes : "predeploy": "npm run build", "deploy": "gh-pages -d build" } }

Remplacez VOTRE-NOM-UTILISATEUR par votre nom d'utilisateur GitHub et NOM-DU-DEPOT par le nom de votre dépôt.

4

Créer un dépôt sur GitHub

  1. Allez sur https://github.com
  2. Cliquez sur "New repository"
  3. Nommez-le mon-app (ou le nom que vous souhaitez)
  4. Ne cochez aucune option (ne créez pas de README, .gitignore ou license)
  5. Cliquez sur "Create repository"

Créez le dépôt vide pour éviter les conflits lors du premier push.

5

Initialiser Git et pousser sur GitHub

Dans votre terminal, à la racine de votre projet React :

git init git remote add origin https://github.com/VOTRE-NOM-UTILISATEUR/mon-app.git git add . git commit -m "Initial commit" git branch -M main git push -u origin main

Ces commandes initialisent un dépôt Git local, le connectent à votre dépôt GitHub, et poussent votre code sur la branche principale.

6

Déployer sur GitHub Pages

Exécutez la commande de déploiement :

npm run deploy

Cette commande va :

  1. Créer une version optimisée de votre application (dans le dossier build)
  2. Créer une branche gh-pages dans votre dépôt GitHub
  3. Pousser les fichiers compilés sur cette branche

Votre application est maintenant en cours de déploiement !

7

Accéder à votre site

Après quelques minutes, votre application sera disponible à l'adresse :

https://VOTRE-NOM-UTILISATEUR.github.io/NOM-DU-DEPOT

Pour configurer GitHub Pages :

  1. Allez dans votre dépôt GitHub
  2. Cliquez sur Settings > Pages
  3. Vérifiez que la source est gh-pages branch
  4. L'URL de votre site est affichée en haut de la section Pages

Problèmes fréquents et solutions

Page blanche en production

Vérifiez que vous avez bien configuré la propriété "homepage" dans votre package.json.

Assurez-vous que tous les chemins dans votre application sont relatifs (utilisez ./ au lieu de /).

Problèmes de chemins

Dans React Router, utilisez le composant HashRouter au lieu de BrowserRouter :

import { HashRouter } from 'react-router-dom'; function App() { return ( <HashRouter> {/* Vos routes */} </HashRouter> ); }
Fichiers JS/CSS introuvables

Vérifiez que le dossier build a été correctement généré.

Exécutez npm run build localement pour tester la génération des fichiers.

Supprimer GitHub Pages

Pour supprimer votre site :

  1. Allez dans Settings > Pages
  2. Cliquez sur le menu déroulant et sélectionnez None
  3. Supprimez la branche gh-pages dans votre dépôt

Bonus : Déploiement avec Vite

Pour les projets utilisant Vite au lieu de Create React App :

Configuration Vite
package.json

Configuration de vite.config.js

Ajoutez la propriété base dans votre fichier vite.config.js :

import { defineConfig } from 'vite' import react from '@vitejs/plugin-react' export default defineConfig({ plugins: [react()], base: '/NOM-DU-DEPOT/' })

Remplacez NOM-DU-DEPOT par le nom de votre dépôt GitHub.

Configuration de package.json

Ajoutez les scripts de déploiement :

{ "name": "mon-app-vite", "version": "0.1.0", "scripts": { "dev": "vite", "build": "vite build", "predeploy": "npm run build", "deploy": "gh-pages -d dist" }, "homepage": "https://VOTRE-NOM-UTILISATEUR.github.io/NOM-DU-DEPOT", "devDependencies": { "gh-pages": "^5.0.0" } }

Notez que le dossier de build est dist au lieu de build.

Les commandes de déploiement restent les mêmes : npm run deploy après avoir configuré votre dépôt GitHub.

Étapes rapides

  1. Créer l'application React
  2. Installer gh-pages
  3. Configurer package.json
  4. Créer le dépôt GitHub
  5. Pousser le code sur GitHub
  6. Exécuter npm run deploy
  7. Accéder au site en ligne

Points clés

  • Le nom du dépôt détermine l'URL finale
  • Le fichier package.json est essentiel
  • La branche gh-pages est créée automatiquement
  • Les mises à jour nécessitent un nouveau déploiement
  • GitHub Pages ne supporte pas le back-end

Chronologie

  • Création du projet : 1-2 minutes
  • Configuration : 3-5 minutes
  • Premier déploiement : 2-5 minutes
  • Mises à jour : < 1 minute
